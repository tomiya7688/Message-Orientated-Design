# Message Orientated Design Checker

This directory contains the auxiliary checker for Message Orientated Design.

The design specification itself lives in the repository-level `docs/` directory. The Japanese version under `docs/jp` is canonical.

The checker must follow the design specification; the design specification must not be shaped around checker implementation convenience.
