# 00. Origins of Object Orientation

In Alan Kay's and early Smalltalk's line of thought, the center was not the class hierarchy itself, but **protected entities interacting through messages**.

Kay later again described messaging, rather than classes, as the central idea of Smalltalk.

This project starts from that direction. However, Sender / Receptor, hierarchical Managers, immutable Messages, and the rest of this specification are design choices made by this project. This is not a historical reimplementation of Smalltalk.

To distinguish it from the common modern meaning of “object-oriented”, this project uses the name **Message Orientated Design**.
